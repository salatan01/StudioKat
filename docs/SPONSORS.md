## Sponsor Display (Historical)

> **Note:** The original OpenMontage README included a Sponsors section. StudioKat's README does not currently include sponsor placement. This section is preserved for reference if sponsor display is added in the future.

The original sponsor convention (from OpenMontage):

- Store sponsor logos in `assets/sponsors/`.
- Use lowercase kebab-case filenames (e.g., `acme-video.svg`).
- Prefer SVG; use PNG only when vector artwork is unavailable.
- Keep logos transparent, tightly cropped, readable at `44px` height.
- Link to the sponsor's official website or product page.
- Use descriptive alt text (e.g., `Acme Video logo`).
