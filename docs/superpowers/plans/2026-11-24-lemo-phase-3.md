# Lemo Engine Phase 3 — Host-Pipeline Integration and Optional Foley

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a host pipeline request a `lemo` B-roll clip, render it, and place it in an edit — with one proved end-to-end host fixture — and add opt-in per-style foley for styles whose vendored sound module is compatible.

**Architecture:** The `scene_plan` `lemo` block already validates (Phase 0). Phase 3 adds a small `host_wiring` helper that builds a schema-valid `broll` scene and its `asset_manifest` entry, wires the `editor` and `animated-explainer` scene/asset/edit directors to use it, proves one host fixture that renders a lemo clip and places it, and adds a foley capability that is declared per style and gated in `lemo_render`.

**Tech Stack:** Python 3.11 (StudioKat venv), Node 22 + Chromium from the Nix shell, ffmpeg 8, JSON Schema, pytest.

**Spec:** `docs/superpowers/specs/2026-11-23-lemo-style-engine-design.md` (§9.8 integration, §11 inputs, §14 Phase 3)

**Depends on:** `docs/superpowers/plans/2026-11-24-lemo-engine.md` (Phase 0/1) and `docs/superpowers/plans/2026-11-24-lemo-phase-2.md` (all fifteen samples) — both completed and approved.

## Global Constraints

- Engine name is `lemo`; every `engine` / `system` / `render_runtime_used` value is exactly `"lemo"`.
- A host pipeline's B-roll scenes render through `lemo_render`, never through `video_compose`: a `broll` scene carrying a `lemo` block is the lemo engine's work.
- The host pipeline's own `render_runtime` is unchanged by adding a lemo broll scene; the lemo MP4 is an input asset the edit/compose stages place.
- The first release is silent (`sound: "none"`) except where a style explicitly declares a compatible foley module; foley is per-style procedural sound only — no narration, score, subtitles or loudnorm.
- `scene_plan` `lemo` blocks are valid only on `type == "broll"`; the schema already enforces this and must keep doing so.
- `asset_manifest` lemo entries use `type: "video"`, `source_tool: "lemo_render"`, `subtype: "broll"`, and a `scene_id` that matches the scene.
- Shared schemas stay additive; editor/faceless/lemo gates keep their existing behaviour.
- Work in place on `master`; commit with `git -c commit.gpgsign=false`.
- No `pytest.skip`, `xfail`, or allowlist that hides a real failure. Any integration step that needs Node/Chromium is an explicit command run under `nix develop -c bash -lc '<cmd>'`, never a hidden skip.
- Run Python as `.venv/bin/python -m pytest ...` from the repo root.

## Review Focus

1. **A lemo block on a non-`broll` scene:** `scene_plan` must reject it. Test: Task 1 (`test_lemo_scene_builds_a_valid_broll` + a negative case) and Task 10 contract tests already in place.
2. **An `asset_manifest` entry that points at a lemo clip the host engine cannot read:** the entry must name the rendered file's real path/resolution/duration, so the edit stage never places a missing or mislabelled asset. Test: Task 1 (`test_lemo_asset_matches_the_manifest`).
3. **Runtime confusion:** adding a lemo broll must not flip the host pipeline's `render_runtime` or route it through `video_compose`; the `render_runtime_selection` decision stays the host's. Test: Task 4 fixture asserts `edit_decisions.render_runtime` is the host's value, not `"lemo"`.
4. **Foley on a style that ships no compatible module:** `lemo_render`/validate must reject `sound: "foley"` for that style rather than emit a silent-but-labelled clip. Test: Task 5.
5. **A host fixture that renders but never places the clip:** the edit stage must reference the lemo asset in `edit_decisions` at the scene's time range. Test: Task 3.

from tests.contracts.test_phase0_contracts import sample_artifact
from tools.video.lemo.host_wiring import lemo_broll_asset, lemo_scene

def _plan(scene):

    return plan

def test_lemo_scene_builds_a_valid_broll():
    scene = lemo_scene("beat_1", "swiss-motion", "A tide timetable", 6)
    assert scene["type"] == "broll" and scene["lemo"]["style_id"] == "swiss-motion"

def test_lemo_block_rejects_a_non_broll_scene():

    import pytest

def test_lemo_broll_asset_matches_the_manifest():
    asset = lemo_broll_asset("beat_1", "beat_1_broll",
                             "projects/demo/assets/video/beat_1.mp4",
                             duration_seconds=6, resolution="1920x1080")
    manifest = {"version": "1.0", "assets": [asset]}
    validate_artifact("asset_manifest", manifest)
    assert asset["source_tool"] == "lemo_render" and asset["subtype"] == "broll"
