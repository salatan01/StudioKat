# Lemo Engine Phase 2 — Remaining Twelve Styles

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one rendered, QA'd sample clip (at the style's default length) in both 16:9 and 9:16 for each of the twelve lemo styles not covered by the Phase 1 pilots, so all fifteen styles have an approved sample.

**Architecture:** Each style's sample is an agent-authored `index.html` + `clip.js` (plus `clip.json`, and for the four input-dependent styles the curated `samples/<id>` inputs) committed under `.agents/skills/lemo/samples/clips/<id>/`. A single parametrized contract test and `pilot_accept.py` prove every sample conforms to its registry manifest and renders clean. The twelve are reviewed in four groups of three; each group ends at a human look gate.

**Tech Stack:** Python 3.11 (StudioKat venv), Node 22 + Chromium from the Nix shell, ffmpeg 8, JSON Schema, pytest.

**Spec:** `docs/superpowers/specs/2026-11-23-lemo-style-engine-design.md` (§7 slate, §10 authoring model, §11 inputs, §12 gates, §14 Phase 2)

**Depends on:** `docs/superpowers/plans/2026-11-24-lemo-engine.md` (Phase 0/1) — completed and approved.

## Global Constraints

- Engine name is `lemo`; every `engine` / `system` / `render_runtime_used` value is exactly `"lemo"`.
- Exactly these 15 ids: `silkscreen-poster`, `swiss-motion`, `bauhaus-shapes`, `flat-space-explainer`, `assembly-line-diagram`, `midcentury-toon`, `living-screencast`, `isometric-picture-book`, `briefing-board`, `dataviz`, `ink-wash`, `paper-popup`, `teardown`, `ascii-crt`, `art-deco`.
- Phase 2 samples use the style's `default_duration_seconds` — 6 s for most, but **8 s** for `assembly-line-diagram` and `flat-space-explainer` (their manifest windows start at 8 s). Never hardcode 6 s; read `get_style(style)["default_duration_seconds"]`. Samples are `fps: 24`, `sound: "none"`, rendered in `16:9` and `9:16` (every remaining style lists `9:16` in its manifest).
- First release is silent: no TTS, score, subtitles, loudness pass, or audio stream.
- The fifteen briefs already exist and are frozen; Phase 2 does not rewrite a brief. `verbatim_check.py` must stay `ok` for all fifteen (regression only).
- Input-dependent clips (`briefing-board`, `living-screencast`, `teardown`) read the curated `samples/<id>` inputs and label them sample/illustrative on screen; never invent evidence.
- No template placeholder may remain in a shipped sample (`__TITLE__`, `One idea`, `subject`, `TODO`); no `Math.random()` or `Date.now()` in `clip.js` — the frame is a function of `t` alone.
- Repository scan stays clean: no upstream `.md` in the vendored tree except licence texts, no `STYLE.md`/`DEMO.md`, no Clawd/Anthropic, no `occt-import-js`/STEP/KiCad/CAD data.
- Work in place on `master`; commit with `git -c commit.gpgsign=false`.
- No `pytest.skip`, `xfail`, or allowlist that hides a real failure.
- Run Python as `.venv/bin/python -m pytest ...` from the repo root. Node, npm and Chromium come only from the Nix shell: run every `node`/`npm`/render/ffprobe command as `nix develop -c bash -lc '<cmd>'` (it exports `CHROME`); the bare shell has no `node`.

## Review Focus

1. **Input-dependent style with the sample inputs:** a `briefing-board`, `living-screencast` or `teardown` clip must load the curated sample input from `samples/<id>/`, declare it in `clip.json.inputs`, and never present invented data/objects as real. Tests: Task 1 (`test_sample_inputs_resolve`) + Tasks 8/11/15.
2. **Aspect outside the style's menu:** a style that lists fewer aspects (`flat-space-explainer`: 16:9/9:16/1:1; `paper-popup`: 16:9/9:16/1:1; `assembly-line-diagram`/`teardown`/`briefing-board`: no 1:1/4:5) must reject an aspect it does not list, and every sample must render both 16:9 and 9:16. Tests: Task 1 (`test_sample_matches_registry`) + the group gates.
3. **Blank or broken frame from a new style's imports:** a sample that does not load `/core/lib.js` or a vendored demo module through the `/@film/` mount must fail `validate`, never render a blank frame. Tests: Task 1 (`test_sample_has_authored_files`) + each style task's validate step.
4. **Determinism:** a sample that reaches for `Math.random()`/`Date.now()` renders differently per frame. Tests: Task 1 (`test_sample_is_deterministic`).
5. **Demo-story reuse (originality):** a sample must not reuse the demo's subject, character, copy or signature composition; `verbatim_check.py` stays `ok` and the reviewer reads each clip against its demo. Tests: Task 1 + every group gate.

```python
# tests/lemo/test_style_samples.py
"""Every shipped sample clip must agree with its style registry entry.

Phase 1 ships three pilots; Phase 2 ships the other twelve. Each sample lives
under ``.agents/skills/lemo/samples/clips/<style>/``. This test keeps every
sample honest: format inside the style window/menu, statically valid, authored
files present, deterministic, and inputs that resolve on disk.
"""
import json
from pathlib import Path
import pytest
from styles.lemo.loader import get_style
from tools.video.lemo.validate_clip import validate_inputs, validate_static

REPO_ROOT = Path(__file__).resolve().parents[2]
CLIPS = REPO_ROOT / ".agents/skills/lemo/samples/clips"

SAMPLE_STYLES = [
    "silkscreen-poster", "swiss-motion", "bauhaus-shapes", "flat-space-explainer",
    "assembly-line-diagram", "midcentury-toon", "living-screencast",
    "isometric-picture-book", "briefing-board", "dataviz", "ink-wash",
    "paper-popup", "teardown", "ascii-crt", "art-deco",
]


def _clip(style):
    return json.loads((CLIPS / style / "clip.json").read_text(encoding="utf-8"))


@pytest.mark.parametrize("style", SAMPLE_STYLES)
def test_sample_matches_registry(style):
    doc, manifest = _clip(style), get_style(style)
    lo, hi = manifest["duration_seconds"]
    assert doc["style_id"] == style
    assert lo <= doc["duration_seconds"] <= hi
    assert doc["aspect"] in manifest["aspects"]
    assert doc["fps"] in manifest["fps"]
    assert doc["sound"] in manifest["sound"]


@pytest.mark.parametrize("style", SAMPLE_STYLES)
def test_sample_is_statically_valid(style):
    assert validate_static(_clip(style), get_style(style)) == []


@pytest.mark.parametrize("style", SAMPLE_STYLES)
def test_sample_has_authored_files(style):
    for name in ("index.html", "clip.js", "clip.json"):
        assert (CLIPS / style / name).is_file(), f"{style}/{name}"
    assert "READY" in (CLIPS / style / "clip.js").read_text(encoding="utf-8"), style


@pytest.mark.parametrize("style", SAMPLE_STYLES)
def test_sample_is_deterministic(style):
    src = (CLIPS / style / "clip.js").read_text(encoding="utf-8")
    assert "Math.random(" not in src, style
    assert "Date.now(" not in src, style


@pytest.mark.parametrize("style", SAMPLE_STYLES)
def test_sample_inputs_resolve(style):
    assert validate_inputs(_clip(style), CLIPS / style) == []
```
